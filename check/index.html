A development instrument. It inspects the browser and prints what it finds. Nothing leaves this device unless you press Send report at the bottom.

How to get a full result:
  1. Press every button on the TV remote, so the Remote buttons section records the key map.
  2. Press the two buttons under Screen — fullscreen and wake lock need a real button press to test.
  3. Close the browser completely, reopen this page, and check whether storage survived.
  4. Press Send report at the bottom. It goes straight to the developer's report sheet — no copying needed. (Or Build report and copy it, where the clipboard works.)
